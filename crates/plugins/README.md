# NovaPlayer 服务插件：网易云音乐 / QQ音乐

独立进程，协议见 [`../../docs/plugins.md`](../../docs/plugins.md)。服务细节仅在插件中；
`kit` 复用管道、HTTP、M3U8 和响应记录，`../plugin-protocol` 提供宿主与插件共用的 JSON
值类型/解析器（不依赖 HTTP 或任何服务）。

- `ncm`：weapi 请求加密（AES-128-CBC ×2 + RSA），实现参照 NeteaseCloudMusicApi 4.32.0。
- `qqmusic`：网页扫码登录、musicu.fcg 业务接口，参照 L-1124/QQMusicApi；歌词密文按
  folia-major 的 QRC 流程做 3DES 解密、zlib 解压。普通请求携带 web profile 的账户 cookies。

这些是服务适配实现，不代表官方 API、授权或持续可用性保证。仅使用本人获准访问的账号与内容；
接口及版权限制以服务为准。未包含用户凭据。代码中的协议固定常量不等于用户登录令牌。

## 构建与安装

在仓库根目录下执行（Windows 或 Linux）：

```sh
python tools/plugins.py
```

脚本构建两个插件，把每个打成一个 zip，放到 `target/dist-plugins/NovaPlayer-plugin-<id>-<Windows|Linux>-x64.zip`。
包内有 `plugin.json`、它声明的程序，以及声明了控件时控件的 `.nui`（两个插件现在都不声明控件：歌词翻译/罗马音按钮由播放器自带）；
缺任何文件就失败，所有包都完整后才替换旧产物。仓库里的清单写的是 Windows 程序名（`*.exe`），Linux 包里的清单写 Linux 程序名。

NovaPlayer 标题栏 ☰ → 安装插件…，选择对应系统的 `NovaPlayer-plugin-ncm-…zip` 或 `NovaPlayer-plugin-qqmusic-…zip`（不是文件夹），
点击插件行打开它的面板，在面板里按两次「启用」：第一次展示权限与联网声明，第二次确认。连接后扫码，选择要导入的歌单。
手工安装可复制完整包目录到应用插件目录；更新后重新加载并重新确认指纹。

歌单链接支持 `music.163.com`、`y.qq.com` / `i.y.qq.com` 的完整分享链接，以及插件 URI。
**不支持 `163cn.tv` 短链接跳转**；请先在浏览器取得完整歌单地址。

Linux 可通过 Cargo 构建两个 binary，但本打包脚本仅面向 Windows；手工打包需把 manifest 的
`exec` 改成实际无 `.exe` 的文件名（声明了控件时同时保留其 `.nui`）。

## 音质

- 网易云默认 **lossless 无损**，不是最高音质。音质菜单可选 jymaster 超清母带、
  jyeffect 高清臻音、hires 高解析度无损、lossless 无损、exhigh 极高、higher 较高、standard 标准。
  服务可降级；空流地址才依次回退，网络错误不伪装成无版权。未提供 sky/杜比多声道选项。
- QQ音乐按 AI00 → Q000 → F000 → OGG 640/320 → MP3 320 → OGG 192 → MP3 128 → AAC
  请求候选，取服务返回的首个可播放地址。没有音质菜单；不请求加密音频文件。
- 服务下架/不给流的歌曲不能播放；QQ 歌单中明确不可用的歌曲被跳过并计数。
  网络失败不会故意包装成这些歌曲无版权。

## 预算与限制

- 每个宿主调用共享有限网络预算：普通调用 18 秒、歌单 175 秒（宿主分别为 20/180 秒）；
  每次 HTTP 最长 10 秒且不得超过剩余预算。无后台自动重试；歌单详情最多尝试 3 次，
  总预算包含等待。HTTP 响应最多 16 MiB；歌词解压最多 2 MiB，拒绝损坏/截断数据。
- JSON 行最多 16 MiB，解析嵌套最多 64 层；数字保留原 API 的 `f64` 表示，超过 2^53 的整数
  可能舍入。需要精确的大标识应通过字符串传递。
- QQ 刷新凭据按原 token 缓存在当前插件进程，重复调用不丢失刷新结果；切换账号、缺 token、
  退出登录会清理。协议没有刷新 token 写回接口，进程重启后仍收到旧 token：能刷新则再刷新，
  否则需要重新扫码。不要把进程缓存误当成持久化凭据更新。
- 歌单最多 100000 首；用户歌单接口目前仅取首批（网易云 1000，QQ 收藏 100），不声称完整分页。
- 返回标准 LRC；QQ 逐字 QRC/XML 排版不支持。主歌词接口优先，密文接口为回退。
- 元数据/缩略图为尽力获取，网络失败可返回已有部分。平台风控、会员权限、实际登录和播放
  需要使用者在授权账号下验证；离线测试不代表实网通过。
